# Release Notes - v1.0

Welcome to version 1.0 of the application! This release includes several improvements and bug fixes to enhance the user experience and ensure the application runs smoothly.

## 🚀 Features & Improvements

- **Enhanced Password Validation**: The password checking function now ensures that passwords are at least 10 characters long, providing a stronger security baseline for user accounts.
- **Improved Email Validation**: The email validation function now checks for both an "@" symbol and a "." in the email address, ensuring more accurate validation of email formats.
- **Comprehensive Vowel Counting**: The vowel counting function now correctly identifies and counts both lowercase and uppercase vowels, making it more versatile for various use cases.

## 🔒 Security & Fixes

- **Consistent Functionality**: All functions have been verified to work as intended, with no changes in behavior that could affect existing workflows.
- **Code Clarity**: The code has been reviewed and maintained to ensure it is clean, readable, and efficient.

We appreciate your continued support and look forward to your feedback as we move forward with future releases.
